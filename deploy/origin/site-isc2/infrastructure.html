Challenge

  • The model server already runs on the GPU host as a plain container; it must not be restarted
  • Ship the platform around it as one installable unit, reachable from the internet without opening the GPU host
  • Every component has a failure mode an operator can find and fix from a runbook

Relay

Trade-offs

  • kind on one node: real Kubernetes objects and Helm, but no node failure and no GPU scheduling by Kubernetes
  • Model outside the cluster: no restart of a shared model, but the cluster cannot scale it
  • One gateway replica: simple, and the drill shows the cost (18 s of errors)

What I'd change at scale

  • Managed Kubernetes with GPU nodes and the NVIDIA GPU Operator; model as a Deployment
  • Two gateway replicas behind a Service, PodDisruptionBudget, readiness on the database
  • GitOps (Argo CD or Flux) instead of a manual helm upgrade
