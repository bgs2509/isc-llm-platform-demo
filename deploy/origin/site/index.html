  • Slow answers or a growing queue

  • Gateway errors and team limits
  • Upgrade and roll back a release

Built with

vLLM (model server), LiteLLM (gateway), Kubernetes in Docker (kind) and Helm, PostgreSQL, Prometheus, Grafana, FastAPI and plain JavaScript (console), nvidia-smi exporter.

Access

The live console and Grafana start real load on a GPU, so they are protected by a password. The documents and the report are open.
